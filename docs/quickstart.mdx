You can add Nyxor L1 to Core Wallet, MetaMask, or Rabby with the following RPC details:

```json

  "chainId": "0x18075",
  "chainName": "Nyxor L1",
  "rpcUrls": [
```

## 3. Core Protocol Workflows

<Steps>
  <Step title="Claim Test Margin Collateral">
    Navigate to the [Trade Terminal](https://nyxor-protocol.vercel.app/trade) and click **Claim USDx** to receive test margin tokens.
  </Step>
  <Step title="Open Isolated Margin Positions">
    Choose between the **Guarded Market (Nyxor)** and **Standard Market (Naive 24/7)** to experience dynamic leverage adjustments in real time.
  </Step>
  <Step title="Teleport Collateral Across Chains">
    Visit the [Bridge Portal](https://nyxor-protocol.vercel.app/bridge) to move margin collateral between Fuji C-Chain and Nyxor L1 via Avalanche Teleporter.
  </Step>
  <Step title="Verify Consensus Precompiles">
    Use the [Compliance Portal](https://nyxor-protocol.vercel.app/compliance) to inspect wallet allowlist roles enforced at the node mempool boundary.
  </Step>
</Steps>
