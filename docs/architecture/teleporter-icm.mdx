## Trustless Cross-Chain Liquidity

Traditional bridges rely on multi-sig committees or wrapped token custodians that represent single points of failure. 

Nyxor uses **Avalanche Interchain Messaging (ICM)** and **Teleporter**, where messages are validated directly by the consensus layer using aggregated BLS validator signatures under **ACP-77**.

```mermaid

    autonumber

    Trader->>Fuji: Deposit USDx Margin into Teleporter Portal
    Fuji->>Fuji: Emit Avalanche Warp Message (AWM)
    Note over Fuji,Relayer: L1 Validators sign packet with BLS multi-sig
    Relayer->>L1: Relay verified packet to TeleporterMessenger
    L1->>L1: Precompile check (Relayer has Role 1 Clearance)
    L1->>Trader: Credit USDx balance on Nyxor L1
```
